## Decisions

DAG 是项目内普通设计文档，指定前置交付、owner、验收和停止条件；不承担运行状态。图拆开首轮假设路径与新的独立方法对照路径，两轮展开后要求投入回顾，另一路保留所有已承诺来源的接入、七日资格与十四天观察。图形分叉不授权 Agent 并发或外部执行。

只读脚本直接读取 OpenSpec task checkbox，报告 checked/unchecked_ids、文件摘要、archive 与候选收口名单，不写任务状态。缺少 tasks 不等于完成；重复 ID 拒绝。指定 evidence run-id 只允许受限目录名，检查标准证据文件、schema、项目与运行标识/退出状态一致性，不回显任意文档内容或测试日志。test count 和 PG 标记只是日志投影，不以指定历史运行认证当前代码。project_complete 固定 false，表示这不是业务最终验收工具。

本机 PostgreSQL 测试脚本由外层既有 runWithEvidence 保存全生命周期输出和失败退出码；内层创建私有临时目录、trust 临时实例、loopback 动态端口。启动/停止只操作该数据目录，永不从用户配置读取目标。测试只收到临时 DSN；停机失败保留目录并退出失败。finally、进程退出及常规信号清理。SIGKILL 无法提供清理保证；运行中断后需根据临时目录检查自身实例，不能停止用户实例。

使用已安装 initdb/pg_ctl，不新增 PostgreSQL 分发依赖。未安装或启动失败不 skip。生产 PG 测试基座的原 Docker/环境回退路径保留，新 runner 通过显式环境标识优先使用其自建实例；不改变普通集成运行的 skip 策略。

证据 runner 补 URI 脱敏并在返回 stdout/stderr 时也脱敏，避免调用方把原始凭据重新打印。保留退出码与所有证据 schema。动态端口释放和 PG 启动间有竞争窗口，冲突时失败，不能连接占用者代替本实例。
