## Why

为 short-drama-radar 补齐无产品 CLI 的创作文件输入，消费根 MCP 输入请求合同。

## What Changes

- 自描述能力、输入请求、受限 HTTP 传输和一次性页面。
- 复用本项目领域服务、原引用、权限与导入规则。
- 默认关闭，既有接口和只读凭据不扩权。

## Capabilities

### New Capabilities
- `mcp-input-intake`: 可恢复的远程创作文件输入。
