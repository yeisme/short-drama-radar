# 建立爬虫主路的短剧爆款雷达 CLI

## Why

短剧编剧/制片/投放团队需要每天 8:59 前拿到已筛选排序的选题情报。官方开放平台均无全平台热榜能力（抖音仅授权账号数据、小红书公开入口偏电商），因此以爬虫为主路、第三方数据作交叉校验。

## What Changes

- 新建 `short-drama-radar` Bun CLI：四层采集（firecrawl 公共页 / agent-reach 平台后端 / Playwright 兜底 / 人工导入）、SQLite 快照与去重、v0 评分（0.40 传播增速 + 0.25 题材频次 + 0.20 钩子密度 + 0.15 情绪强度，confidence < 0.6 转人工）、`short-drama-radar.card.v1` 卡片合同输出。
- 账号池+代理池轮换与熔断降级（不自动绕过验证码）。
- 集成测试证据写入 `temp/integration-test-runs/`。

## Impact

- 影响面：仅本子项目；云婉侧需实现卡片合同消费者（外部项目，另行立项）。
- 风险：平台风控导致账号封禁；14 天验证期以账号池存活率为核心健康指标。
