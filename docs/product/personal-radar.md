# Radar 个人自用方向

2026-09-17 用户调整：只做中国大陆、香港、台湾、日本、韩国及欧美地区，自己使用，不招募受众。此决定替代此前以访谈、询价、独立对照和两轮观看实验为主线的推进计划。

## 当前目标

每天用一份简报发现值得看的短剧／漫剧、值得收藏的题材和可参考的创作方向。用户自己决定看什么、存什么、尝试什么，Radar 保存证据和判断变化。

## 地区范围

- 中国大陆：单独整理来源、作品与趋势。
- 香港、台湾：可以合并为导航分组，证据仍按 HK、TW 分开，不能因为繁体中文就认定受众地区。
- 日本、韩国：分别保留 JP、KR 与日语／韩语原文，设计与已知缺口见[日韩场景](personal-jp-kr.md)。
- 欧美：作为阅读分组；具体记录保留国家、语言和来源。起步可优先美国、英国及有可靠公开来源的欧洲市场，加拿大等按实际来源补充；这只是实施顺序，不是机会排名。暂不扩展到拉美。

印尼及其他不在当前范围内的扩展暂停，已有资料和历史记录保留。来源是否可用以实际核验为准；欧美入口不代表整个欧美市场，英语作品不自动属于美国。

## 最短使用路径

公开来源核验 → 作品去重与地区标记 → 每日简报／机会候选 → 自己收藏或略过 → 每周回看判断。

简报先控制在易读的少量条目：作品／题材、来源链接、地区依据、为什么值得看、证据缺口。没有可靠信号就明确写缺数据，不为了填满地区版块编排名。无需先完成全部来源接入才开始用。

现有晨报、关注、补看、跨市场对照、个人反馈和生产交接继续复用。自己喜欢是个人偏好，不写成市场验证；收藏与真实采用沿用现有不同反馈语义，不能随意把收藏记为 used。决定创作后才进入 Auctra／Scaena 的可选交接。

## 下一轮工作

先核查这几个地区的已有来源及字段覆盖，形成可用／缺数据清单；再打通一份可供本人阅读、收藏和补看的简报。优先修正地区混淆、重复作品、失效链接和解释不清的问题。随后根据自己的真实使用反馈调整排序。

验收看简报是否省时间、来源能否查证、是否帮助自己发现和选择方向。不招募、不做供应商询价、不以独立研究者、盲审或受众 A/B 作为日常使用前置条件。实验命令作为已有可选工具保留，不自动启动实验。

来源资格、数据真实性、隐私与兼容要求继续保留。既有十四天 canary 可用于自己的持续质量回顾，不阻止今天开始使用；不将未发生的观察补写成通过记录，也不把旧计划中暂停的任务勾成完成。

## 已有入口

从 Radar 子项目目录检查现有能力：

```bash
bun run src/cli.ts market source list --json
bun run src/cli.ts --help
```

本文只调整产品范围与执行顺序，不声称地区来源、每日自动采集或地区排序已全部实现。旧任务统计在正式调整前仍可能包含原范围待办，不能直接作为当前个人版的完成率。

## 当前阅读能力与接续

已接通一次日语／韩语语言目录采样，并新增[中文标题阅读层](../runtime/chinese-reading.md)：原文和译文并列、简繁分别保存、缺失或过期回退原文。它不是官方译名或题材证据，不改变作品归属。

后续依次推进：小批量作品详情／形式核验 → 有可靠原文后扩展简介翻译 → 补齐 HK/TW 共享地区注册 → 改善个人收藏、关注和补看的中文阅读。复用既有模型，不新增招募、独立 UI 或翻译平台。
