# 首轮研究的来源、方法与基线

本轮于 2026-09-16 核对公开网页。本文是供人审阅的研究笔记和参考文献，不是 Radar 的采集回执、来源资格记录、实验预注册或反馈账本。网页查询没有把来源晋级为 `sample_verified` 或 `qualified`。

## 研究前的用户基线

用户在本轮研究结果展示前明确回答：没有原本最想做的 1–2 个漫剧方向。这是“用户原始选题基线缺失”，不能解释成用户选错、Radar 已改善选择，或零分对照。

已经确认的要求是：市场机会优先；漫剧／动画短剧；寻找已有需求中的差异化；市场也需要选择；广泛初筛后三市场深查；以立项决策包支持取舍；通过小样观察观看和继续观看行为；连续两轮未优于基础方法时暂停扩展、复查原因。

截至本文交付，用户没有提供预算上限、现成受众池、语言能力或制作报价。本包给出的样本数和判定阈值是实验设计建议，费用是明确假设下的计算示例，均不是已取得的执行条件。

首轮可以检验“是否形成了有依据的选择”和“某个差异化假设是否得到支持”。要比较 Radar 与基础选题方法，必须按[实验方案](experiment-design.md)先取得没有看过本包的独立对照。当前研究者已接触 Radar 资料，不能再充当盲态对照作者。

## 覆盖方式和局限

研究问题：哪些地区／语言有与漫剧相关的内容供给和消费线索，值得继续调查可验证的选题差异？时间截止为 2026-09-16；历史报告保留原统计窗口。覆盖中国大陆、美国、墨西哥、巴西、印尼、印度、泰国、菲律宾、日本、韩国、英国、德国、法国共 13 个初筛位置。

纳入官方产品页、官方作品详情、平台公开分类／榜单、发行方公告、直接发布的行业研究以及招募服务说明。排除与查询无关的搜索摘要、错误跳转、只有站点导航的页面和没有定义的数值。作品名称和简介只用于研究主题与形式，未取得改编权，也没有复制剧本或生成其衍生作品。

工具与检索边界：

- 首选已配置的 Firecrawl。五次关键词检索分别围绕国内漫剧用户、短剧地区结构、WEBTOON 影像、Sensor Tower 短剧、漫剧用户规模，返回 7、7、7、6、6 条结果，共 33 条。结果大多忽略限定词；这些检索结果均未直接作为结论证据。
- Firecrawl 站点映射的关键词过滤也没有得到相关结果；备用网页搜索接口返回不可用。直接 Google 检索返回跳转壳，DuckDuckGo 返回人机挑战，Bing 与本地搜索存在相同的相关性问题。没有绕过验证或修改检索服务。
- 随后从既有官方地址、站内链接和作品页进行定向读取。对腾讯动漫保留路径大小写；部分路径返回目录而非作品正文，重新读取正确路径后才纳入作品详情。
- 下表是全部 27 个纳入本包引用的页面，按实际引用 URL 去重。相同页面的重试、目录中的数十部作品以及各语言首页上的全部链接均不另算样本。它不是随机市场样本，也不是全网检索结果集。
- 来源集中于约 8 个发布主体／平台组：Sensor Tower、红果、腾讯、快看、WEBTOON／LINE、ReelShort、NetShort、Prolific。Apple 是商店宿主，不另算需求印证；腾讯动漫与火龙、同一 WEBTOON 的多语言页面也不能算独立市场印证。
- 作品层细读 7 页：中文 2 部漫画、英语 1 部平台标注动画及 2 部漫画、印尼语 2 部漫画。没有观看整部作品，没有取得留存、完播、投流、地区受众或作品收入数据。

## 可复核的读取示例

这些命令只用于重新取得公开内容；后续页面可能发生变化。它们不创建 Radar 的来源资格或实验结果。

```bash
firecrawl scrape 'https://about.webtoon.com/press-release/255' --only-main-content --format markdown
firecrawl scrape 'https://ac.qq.com/Comic/comicInfo/id/639297' --only-main-content --format markdown
firecrawl scrape 'https://www.prolific.com/pricing' --only-main-content --format markdown
```

本次没有登录平台、启动采集定时器、购买数据、招募受众、发布作品或创建虚构反馈。来源样本与本地软件测试、真实观看实验是三种不同证据。
