# 首轮漫剧立项决策包

2026-09-16 完成公开资料研究与实验设计草案。推荐尚未经过目标受众验证，也没有获批生产。用户原始选题基线为“没有”，详见[研究笔记](research-notes.md)。

后续软件已支持 [`radar decision` 本地记录闭环](cli-guide.md)。本研究文档不会自动入库，也没有因此获得观看验证；下面保留首轮研究时的判断与产品化依据。

新增[本轮 G1 补证](g1-evidence-update.md)已对 EN-A 的宽泛差异化提出反例，并核实招募地域与筛选成本；下文保留最初研究判断，新的执行要求见[准备包](g1-execution-pack.md)。

## 决策建议

**优先验证 EN-A：成年主角具有主动选择权的奇幻关系漫剧；CN-B：有明确代价的奇幻经营，作为备选。** 首个拟测试受众是居住美国、日常消费英语奇幻／关系类漫画或短动画的成年人。这个受众定义是招募假设，不是平台已经披露的人群画像。

推荐 EN-A 的依据：有可逐部核验的平台动画标签作品，也有相邻关系题材漫画；“增加主角主动选择是否提高继续观看”可以被小样检验。它符合市场机会优先的选择，不以用户现有制作能力作为硬过滤。[直接竞争入口](https://www.reelshort.com/movie/sister-stole-my-mate-i-got-the-dragon-king-6a8f9c5571f9039e440f4c2a) · [相邻阅读参照](https://www.webtoons.com/en/romance/maybe-meant-to-be/list?title_no=4208)

**尚不足以支持投入整季。** 目前没有美国地区的该类作品留存，也没有证明观众觉得主角缺少主动权。下一步是形式抽查、目标受众问题访谈和母语制作可达性确认。若没有找到这一问题，撤回 EN-A 的优先级，而不是继续堆积支持材料。

三市场深查及未入选地区的缺口见[市场研究](market-research.md)。研究优先级不等于国家市场排名。

## 六个可比较的候选

这些名称仅用于本次人工讨论，不是新协议枚举或已写入 Radar 的机会记录。以下年龄、题材兴趣与使用场景都是待筛选的目标定义；代表作品只作为参照，不授权改编。

### EN-A：有主动选择权的奇幻关系

- **谁会看／什么需求：** 熟悉奇幻关系冲突、愿意消费英语短动画的成年人；期待强情绪和人物关系推进。具体平台标注动画供给见 R10，关系题材相邻参照见 R13。
- **差异化假设：** 保留危险、误解和关系张力，让主角通过谈判、行动和有代价的选择改变局面；观众可能因此更愿意继续看。没有证据证明现有市场普遍缺少这种表达。
- **为何先验证：** 能在相同制作条件下比较一个明确的叙事机制，且无需把“用户看漫画”直接当成全部动画需求证据。
- **反例／为何可能不选：** 观众可能更需要熟悉的情绪冲击；增加解释和谈判可能拖慢节奏。动画标签也可能不准确，视觉抽查失败就降低直接证据权重。
- **需要补齐：** 美国目标受众、英语母语审读／配音、可比的小样制作；具体报价和渠道尚未确认。
- **如何推翻：** 质量与理解度相近时，主动选择版本未提高继续观看，或削弱情绪张力；按实验规则暂停或修改假设。

### EN-B：超自然成年生活喜剧

- **谁会看／什么需求：** 喜欢超自然设定与关系喜剧的英语成年观众。Vampire Family 的喜剧供给和 Maybe Meant to Be 的成年人物关系是相邻参照，均不能直接证明本候选需求。
- **差异化假设：** 每集解决一个职场或共同生活的小困境，同时推进关系，使观众既得到即时回报又愿意追更。
- **为何暂列后位：** 需要同时验证校园到成年生活、漫画到短动画两次迁移，比 EN-A 多一个关键不确定性。
- **反例：** 幽默高度依赖对白和表演；笑点有效也不一定产生连载期待。
- **需要补齐：** 母语喜剧写作、声音表演和节奏审读。不能仅翻译中文笑话。
- **如何推翻：** 观众认可某个笑点，但不主动继续看第二集；回到人物关系与连载机制，不能以“好笑”判成成功。

### CN-A：有及时回报的奇幻悬疑

- **谁会看／什么需求：** 消费中文奇幻、规则悬疑或推理内容的成年人。红果漫剧介绍中的悬疑题材及《日月同错》的奇幻对抗是线索，尚无同一受众的行为验证。
- **差异化假设：** 每集给出可理解的线索，并回收一个小疑问；用信息推进而非不断增加未知来维持追更。
- **为何保留：** 小样能够测试观众是否理解因果、是否主动寻找下一个答案。
- **反例：** 解答过快可能消除悬念；复杂规则可能增加认知负担。参照漫画也不是公平推理需求的直接证据。
- **需要补齐：** 能经受观众追问的逻辑、分镜可读性、真实悬疑爱好者；先审故事因果，再增加视觉复杂度。
- **如何推翻：** 观众理解线索却没有更高继续观看，或主要因规则负担离开；优先调整机制，不追加更多设定。

### CN-B：有代价的奇幻经营

- **谁会看／什么需求：** 喜欢经营、成长和可见进展的中文成年观众。《放开那个女巫》是明确的漫画参照；动画迁移仍待验证。[作品页](https://ac.qq.com/Comic/comicInfo/id/639297)
- **差异化假设：** 每次成长都对应看得见的资源损失、取舍与后果，让进展值得期待，而非只靠数值升级。
- **为何作为备选：** 可以把“是否理解取舍”和“是否继续看结果”连接起来，候选的实验问题清楚。
- **反例：** 观众可能就是为了轻松的无阻力成长而来；成本细节可能降低爽感。已有漫画不能保证短视频形式成立。
- **需要补齐：** 可视化资源因果、角色连续性、适度解释；制作预算不能用题材标签估算。
- **如何推翻：** 在理解度达标后，增加代价仍降低继续观看；降低该假设优先级，不用更大世界观掩盖失败。

### ID-A：成年合租／工作日常喜剧

- **谁会看／什么需求：** 居住印尼、消费印尼语日常内容的成年人。WEE!!! 提供校园日常的相邻参照；成年生活偏好未知。
- **差异化假设：** 从可识别的生活关系中形成每集小冲突，比通用译配关系故事更能产生认同和回访。
- **为何暂列后位：** 本地触达和母语创作尚未确认，且校园到成年情境的迁移需要独立验证。
- **反例：** 受众也可能偏好脱离现实的内容；“本地化”不一定改善娱乐体验。
- **需要补齐：** 印尼语创作者／审读者、本地成年受众、对白和文化语境校验。
- **如何推翻：** 观众能理解本地生活细节却不愿继续看，或更喜欢通用幻想题材；不继续以国别标签解释需求。

### ID-B：现代日常中的奇幻规则悬疑

- **谁会看／什么需求：** 消费印尼语奇幻连载的成年人。Born from Death 是相邻漫画参照，不能证明本候选的短动画需求。[作品页](https://m.webtoons.com/id/fantasy/born-from-death/list?title_no=615)
- **差异化假设：** 让奇幻规则影响日常选择，使观众能预测、猜测并期待后果。
- **为何暂列后位：** 同时有形式迁移、本地表达和受众可达性缺口。
- **反例：** 受众可能更重视高强度动作，或者不接受故事对当地文化元素的使用。
- **需要补齐：** 母语叙事、当地文化审读、目标受众。未经确认不擅用宗教／民俗符号制造差异。
- **如何推翻：** 规则被理解但没有提高继续观看，或文化语境成为主要障碍；撤回具体表达，重新审视需求。

EN-B、ID-A 的作品详情与形式限制见[来源 R13–R18](research-notes.md)。候选的反例是待检查的失败解释，不是假装已经收集到的用户反馈。

## 验证顺序与交接

1. **研究补证。** 每个深查市场先接触 6 位符合条件的成年人，围绕其最近真实弃看／追更经历访谈；先问经历，再展示候选，避免诱导。三市场不合并计算偏好。
2. **缩到一个市场与一个假设。** 暂以 EN-A 为首选；根据问题是否存在、形式核验、合格受众与制作报价修订。若只证明了资料可信，还没有完成需求验证。
3. **形成制作简报。** 将目标受众、一个待验证差异、反例、相同制作约束和两个版本的交付要求交给 Auctra；由其开发原创内容，再由 Scaena 制作小样。当前六个候选不是六个生产项目。
4. **执行和回顾。** 按[实验方案](experiment-design.md)区分候选假设实验与方法对照实验。观看结果回来后，指出哪个具体判断得到支持、被削弱或仍未知；不覆盖原判断。

## 能力归属与产品投入条件

| 能力 | 归属判断 | 首轮处理 |
| --- | --- | --- |
| 市场证据、来源限制、候选取舍与判断回顾 | fit：Radar | 先以普通研究文档交付，复用既有证据读取能力 |
| 剧本、分镜、小样制作及制作回执 | split-owner：Auctra／Scaena | 本包提供人类可读简报；真实写入用各 owner 的服务合同 |
| 阅读、比较和追问界面 | split-owner：DSH | 优先消费当前可用结果，新界面等反复使用需求明确后再定 |
| 招募、付费、投放和发行 | 本轮人工实验；不作为 Radar 平台能力接入 | 具体执行条件和外部动作另行确认 |
| 新数据服务、多人后台、自动生产审批 | reject-now | 不作为本轮验证的前置工程 |

当前市场简报只是 assignment 的背景证据；这份普通文档不冒充新的 Edition，也不以手写 refs 送入生产。只有真实 Edition 及有效机会才能使用已有 assignment 入口。现在不更改 `card.v1`、Profile、Edition、assignment 或 `used` 的语义。

后续产品化由出现的实际障碍触发：

- 若两轮都重复花费时间对齐作品、形式、地区和证据，优先补可追溯的证据整理；先记录真实工时再估算收益。
- 若比较时频繁丢失原假设与反例，补候选比较与判断修订的 CLI／应用服务；进入本项目 OpenSpec 后增量设计合同。
- 若小样结果无法回到选题判断，先定义外部结果的受控引用与回顾入口，保持制作数据在下游 owner。
- 若关键来源持续缺失，再为该来源投入适配器和资格验证；不按平台数量作为完成指标。

两轮有效方法对照均未达到预先约定的优势门槛时，暂停扩大功能投入，复查证据、推荐方法与小样可比性。真实来源资格和十四天 canary 保留独立验收，不能被本包代替。
